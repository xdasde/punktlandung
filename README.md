# Punktlandung

Aufgaben und Belohnungen für die Familie, gemacht fürs Küchen-iPad. Die App ist eine einzige HTML-Datei ohne Abhängigkeiten.

Alle Daten bleiben lokal auf dem Gerät. In diesem Repository liegt nur die App mit erfundenen Demodaten.

**Installieren:** Die App in Safari auf dem iPad öffnen und mit „Zum Home-Bildschirm“ ablegen.

**Verwaltung:** Die Standard-PIN ist 1234. Sie lässt sich in den Einstellungen ändern. Dort gibt es auch die Datensicherung als JSON-Datei.
